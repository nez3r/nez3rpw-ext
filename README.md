# nez3r.pw
## External модификация для игры Standoff 2.
[![Builds](https://github.com/nez3r/nez3rpw-ext/actions/workflows/main.yml/badge.svg?branch=main)](https://github.com/nez3r/nez3rpw-ext/actions/workflows/main.yml)
### Билдинг:
запустите build*-*.bat, убедитесь что вы установили свой путь к Android NDK.
### Что компилируют батники?
build.bat - arm64-v8a
build-pc.bat - x86_64

### Запуск чита.

Если вы разработчик, то вы можете воспользоваться run.bat для запуска чита. Важно: это только для телефонов, для эмуляторов вы можете использовать run.bat из последнего ПК релиза.

Если вы обычный пользователь, то вы можете просто скачать релизный файл в Telegram канале @nez3rpw, или во вкладке Releases в репозитории.

Для эмуляторов: убедитесь что у вас включена отладка в Bluestacks, запустите файл run.bat в игре.

Для телефонов (ONLY ROOT): распакуйте архив в /data/local/tmp и запустите файл run.sh в игре.
